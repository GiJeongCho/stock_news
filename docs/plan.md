## 2. 기술 스택 선택 (확정)

- **언어**: Python 3.11+
- **브라우저 자동화**: **Selenium 4** (Chrome)
  - Selenium Manager가 드라이버 자동 설치. 고정 프로필(`--user-data-dir`)로 로그인 세션 유지.
  - 봇 탐지 완화: `--disable-blink-features=AutomationControlled`, 클립보드 붙여넣기 입력.
- **로그인 전략**: **지금 즉시 로그인 후 세션 상주 유지** (스크립트를 9시까지 계속 실행).
- **새 글 감지**: 네이버 블로그 RSS(`https://rss.blog.naver.com/studiochoix.xml`) 폴링으로 최신 `logNo` 추적(블록 위험 낮음) + 실패 시 브라우저 폴백.
- **스케줄링**: 스크립트 내부 `while` 루프 + 시각 비교 (9시 근처에서 폴링 간격 단축).
- **설정 관리**: `.env` (python-dotenv)
- **로깅**: `logging` 모듈 + 단계별 스크린샷 저장

## 3. 핵심 난관과 대응 전략

### 3-1. 네이버 로그인 (봇 탐지 / 캡차)
- 자동 타이핑은 캡차·추가인증을 유발하기 쉬움.
- **대응**:
  - `launch_persistent_context`로 고정 프로필 디렉토리 사용 → 최초 1회 로그인 후 세션 쿠키 재사용.
  - 아이디/비번은 `page.type`에 `delay`를 주거나, 클립보드 복사 후 붙여넣기(`Ctrl+V`) 방식으로 입력.
  - 캡차/기기등록 화면이 뜨면 **수동 개입 대기 모드**로 전환 (사람이 해결 후 엔터).
  - 로그인 성공 판정: 로그인 후 `https://www.naver.com`에서 로그인 상태 요소 확인.

### 3-2. 새 글 감지
- 블로그 글은 `PostView` iframe 구조(`https://blog.naver.com/PostView.naver?blogId=studiochoix&logNo=...`).
- **대응**:
  - 블로그 메인 또는 `prologue`/글목록에서 최신 `logNo`를 주기적으로 폴링(예: 5~10초 간격).
  - 시작 시점의 최신 글 `logNo`를 기준값으로 저장 → 그보다 큰 새 `logNo` 등장 시 "새 글"로 판정.
  - 9시 전후로 폴링 간격을 좁혀(1~3초) 반응 속도 확보.

### 3-3. 댓글 기능 활성화 감지
- 네이버 블로그 댓글은 별도 iframe(`https://blog.naver.com/CommentList.naver` 계열) 내부에 위치.
- "댓글 비활성화" 상태일 수 있으므로 활성화 여부를 확인해야 함.
- **대응**:
  - 댓글 iframe 로드 → 댓글 입력 영역(contenteditable `div`) 존재 및 활성 여부 체크.
  - 입력창이 없거나 "댓글을 쓸 수 없습니다" 류 안내가 있으면 비활성 → 짧은 간격 재확인.

### 3-4. 댓글 작성 및 제출
- **대응**:
  - 댓글 입력 영역 클릭 → 텍스트 입력(두 줄: 이름/번호, 해시태그).
  - 해시태그 `#파블로카케이크`가 자동 링크/태그로 변환되는지 확인 (필요 시 그대로 평문 입력).
  - "등록" 버튼 클릭 → 등록 완료 토스트/목록 반영 확인.
  - **중복 방지**: 등록 성공 플래그 저장, 성공 시 루프 종료.

## 4. 실행 흐름 (의사 코드)

```
설정 로드(.env)
브라우저 실행(persistent context)
로그인()  # 세션 없으면 로그인, 캡차 시 수동 대기

base_logno = 블로그_최신글_logNo()

# 9시까지 대기 (예정 시각 전까지 느슨한 폴링)
while now < 2026-10-05 09:00 KST and 새글없음:
    sleep(10); 세션_생존_확인()

# 새 글 감지
while True:
    cur = 블로그_최신글_logNo()
    if cur > base_logno:
        new_post = cur
        break
    sleep(1~3)

# 댓글 활성화 대기
while True:
    글_열기(new_post)
    if 댓글입력창_활성():
        break
    sleep(2)

# 댓글 작성
댓글입력(내용)
등록클릭()
등록확인()  # 실패 시 재시도 (최대 N회)
로그/스크린샷 저장
```

## 6. 안정성 / 예외 처리

- 네트워크 오류, iframe 로드 실패 → try/except + 재시도(backoff).
- 세션 만료 → 재로그인 시도, 실패 시 알림.
- 등록 버튼 비활성/실패 → 최대 N회 재시도 후 로그 남기고 중단.
- 모든 주요 단계마다 스크린샷 저장(디버깅/증빙용).
- **헤드리스 비권장**: 봇 탐지 및 캡차 수동 대응을 위해 `headless=False` 권장.

## 7. 리스크 및 확인 필요 사항

1. **네이버 자동화 탐지**: 로그인/댓글 자동화는 네이버 이용약관 및 정책상 제한될 수 있음. 캡차·추가인증 발생 가능성 존재 → 수동 개입 경로 필수.
2. **실행 환경 상주**: 9시까지 PC가 켜져 있고 스크립트가 중단 없이 실행되어야 함(절전/네트워크 유지 확인).
3. **개인정보 노출**: 전화번호가 공개 댓글로 게시됨. 의도 재확인.
4. **DOM 구조 변동**: 네이버 블로그 UI가 바뀌면 셀렉터 수정 필요 → 실제 블로그에서 셀렉터 사전 검증 권장.
5. **시간 동기화**: PC 시계가 KST 기준 정확한지 확인.
